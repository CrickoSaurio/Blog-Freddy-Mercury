# Freddie Mercury — Una vida detrás de una leyenda

Sitio documental educativo desarrollado con HTML5, CSS3 y JavaScript vanilla.

La estructura se divide en una portada y páginas dedicadas a biografía, Queen, música, presentaciones, legado y fuentes. Las fotografías y fondos indicados en la especificación se cargan desde sus direcciones externas.

Para iniciar el sitio y conservar el audio al navegar entre páginas, abre una terminal en esta carpeta y ejecuta `python -m http.server 8000`. Luego visita `http://localhost:8000`. La reproducción continua requiere este servidor local; abrir cada HTML directamente como archivo provoca una recarga completa al navegar.
